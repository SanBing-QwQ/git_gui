git_gui
通过简单的图形来操作晦涩难懂的命令行git,让小白用户也能自在的使用
但是现在并不支持远程拉取仓库或克隆仓库之类操作，仅支持本地化
包含的功能：
仓库：添加已有仓库 / 把普通文件夹变成仓库 / 多仓库切换


日常操作：
暂存所有更改、提交（可自动生成说明）、查看改了哪些文件

后悔药：撤销提交（保留修改 / 丢弃修改）、反向提交

分支：创建、切换、合并、删除

标签：打标签、附注标签、删除

文件追踪：让 Git 开始/停止追踪某个文件或文件夹

日志：每天的操作记录，自动清理 10 天前的
